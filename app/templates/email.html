{# --- MODAL CORREOS ÚNICOS --- #}

Correos únicos

Qué hace: si está marcado, los correos que añadas manualmente a este usuario no pueden compartirse con otros clientes (usuarios principales).

Al añadir manualmente: si otro cliente ya tiene ese correo, se le quita de inmediato y queda solo en este usuario (el más reciente que lo toma).

Licencias: no aplica. Los correos que entran o salen por Licencias se gestionan aparte y no usan esta exclusividad.

Sub-usuarios: un sub-usuario sí puede tener el correo si su padre lo tiene.

{# --- MODALES PARA APIs VINCULADAS --- #}

APIs Vinculadas proyectos

Qué hace: vincula este usuario con un nombre de proyecto, su IP y el token que usará en esta API de Códigos.

Cómo usarlo: agrega nombre, IP o rango CIDR y token. La URL es siempre la de este proyecto. Con Mi API copias el token de este usuario.

IP: la IP que pegues queda vinculada a este usuario en Documentación API. Sin IP no se aceptan consultas.

Mi API de Acceso para codigos

Usa el token para vincular este usuario. El servidor que consulte debe usar una IP vinculada a este usuario (se agrega en APIs Vinculadas o en Documentación API).

Nota: Cada usuario tiene un token único. No compartas este token con nadie.
