APIs Vinculadas proyectos

Qué hace: vincula un usuario dueño con un nombre de proyecto, su IP y el token que usará en esta API de Códigos.

Cómo usarlo: con Mi API copias el token. Aquí eliges usuario, nombre, IP y token. Probar comprueba IP + token.

IP: la IP que pegues queda vinculada a ese usuario (también aparece en la lista de arriba). Sin IP no se aceptan consultas.

API para las licencias

Qué hace: vincula el mismo usuario dueño con el token que usará en la API de licencias.

Cómo usarlo: con Mi API copias el token. Aquí eliges usuario y token. Probar comprueba IP + token.

IP obligatoria: ese usuario debe tener IP vinculada arriba en esta página.

Mi API de Acceso para proyectos vinculados

Usa este token en otros proyectos para consultar esta API de Códigos. El servidor que consulte debe usar una IP dada de alta arriba, en esta página.

Nota: Cada proyecto tiene un token único. No compartas este token con nadie.
